# Changelog

All notable changes to this project will be documented in this file.

## [1.1] - 2026-01-29

### Added
- AI opponent implementation with minimax algorithm
- Logging support using log4j2
- Comprehensive test coverage for game logic

### Changed
- Updated project version from 1.0-SNAPSHOT to 1.1
- Enhanced game model with AI integration

## [1.0.0] - 2024-03-16

### Added
- Initial release of TicTacToe game
- Basic game functionality with two-player support
- JavaFX-based user interface
- Three-by-three game board
- Win detection for horizontal, vertical, and diagonal lines
